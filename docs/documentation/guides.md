# Guides

Public VyDex pages are designed to be read and navigated directly. Maintainers can use the release guide when a previous complete production deployment needs to be restored.

- [Install, run, and validate VyDex locally](https://github.com/Vyce101/VyDex/blob/main/docs/QUICKSTART.md)
- [Open the VyDex Homepage](https://vydex.pages.dev)
- [Read About VyDex and its Scope Limits](https://vydex.pages.dev/about/)
- [Read the VyDex Methodology](https://vydex.pages.dev/methodology/)
- [Redeploy a complete Stage 1 release](how-to-redeploy-stage-1-release.md)

QUICKSTART remains setup documentation, while the Export JSON page explains its own one-action public download.
