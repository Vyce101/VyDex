# Guides

Public VyDex pages are designed to be read and navigated directly. The production guides are for maintainers operating the protected Cloudflare Pages workflows.

- [Install, run, and validate VyDex locally](https://github.com/Vyce101/VyDex/blob/main/docs/QUICKSTART.md)
- [Open the VyDex Homepage](https://vydex.pages.dev)
- [Read About VyDex and its Scope Limits](https://vydex.pages.dev/about/)
- [Read the VyDex Methodology](https://vydex.pages.dev/methodology/)
- [Redeploy a complete Stage 1 release](how-to-redeploy-stage-1-release.md) when production needs emergency restoration.
- [Rehearse the production rollback](how-to-rehearse-production-rollback.md) after the first verified deployment or a later rollback-mechanism change.

Use the rehearsal guide for the planned rollback-and-restoration test. Use the redeploy guide only when a known-good production deployment must be restored. QUICKSTART remains local setup documentation, while the Export JSON page explains its own one-action public download.
