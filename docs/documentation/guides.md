# Guides

VyDex does not yet have a normal-user task that requires a separate step-by-step guide. The Stage 1 Homepage, Entry pages, and Methodology are designed to be read and navigated directly.

- [Open the VyDex Homepage](https://vydex.vyce.workers.dev)
- [Read the VyDex Methodology](https://vydex.vyce.workers.dev/methodology/)
- [Install, run, and validate VyDex locally](https://github.com/Vyce101/VyDex/blob/main/docs/QUICKSTART.md)

Topic Trail, About, Changelog, and export destinations remain separate Stage 1 work. Task guides will be added when VyDex introduces a normal-user workflow that needs ordered steps, decisions, or warnings. QUICKSTART remains setup documentation rather than a normal-user task guide.
